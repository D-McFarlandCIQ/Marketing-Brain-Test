# Visual identity

The one-page quick reference for anyone, human or agent, making a CaptivateIQ visual.
Details are in [visual/](visual/). Use only the values listed in these files. If you
need something that isn't covered, ask the CIQ brand design team
([resources.md](resources.md#contacts)). Don't invent new values.

## The look in one line

Bright, airy, and confident. Generous white space on light, warm-neutral backgrounds.
On top of that go soft, blurred color fields that overlap like layered glass, with the
20° "Driving Force" angle running through the shapes. Headlines are large and light
with a serif-italic accent. The essence is **wonder + intelligence**.

## Core values to know

| Use | Value |
| --- | --- |
| Core brand dark: dark backgrounds, dark Wordmark | **Galaxy** `#0A2028` |
| Default text and sans headlines | **Almost Black** `#0C1728` |
| Serif headlines | **Taupe 4** `#585858` |
| Default light background | **Taupe 1** `#F5F4F3`, or white |
| The most-used color families | **Lagoon** (teal), **Violet**, **Hedge** (green) |
| Secondary families | **Slate, Taupe, Cirrus** |
| Accents, small details only | **Berry, Citrus** |
| Primary CTA on the site | Hedge 2 `#B5EF71` background, dark text |

## Typography

| Role | Brand font (licensed) | Free alternate |
| --- | --- | --- |
| Headlines (H1–H3) | **Neue Haas Grotesk Pro**: Extra Light for H1, Roman for H2 and H3 | Public Sans |
| Accent words in headlines, quotes | **IvyPresto Headline**: Thin or Light Italic | Newsreader |
| Sub-headers (H4) | **Fakt Medium** | Public Sans |
| Body | **Fakt Regular** | Public Sans (Manrope is legacy and being phased out) |

The brand fonts are licensed only to brand-team seats and the website. Everyone else,
including the company Google Slides template, uses the alternates. See
[visual/typography.md](visual/typography.md).

## The ten rules

1. **Lead with white space.** Then Lagoon, Violet, or Hedge, then the neutrals. Use
   Berry and Citrus only for small accents.
2. **Blend, don't block.** Use one light base, one or two blurred color layers, and one
   small accent. Avoid flat, hard-edged color blocks.
3. **Type is Almost Black or White.** Use brand colors only for brief emphasis, never
   for long passages.
4. **White must read distinctly** against any light base you pick.
5. **Use the 20° angle** for shapes, patterns, and illustrations
   ([visual/graphic-language.md](visual/graphic-language.md)).
6. **Corners follow 4 / 8 / 16 / 24px** (the 8-point system).
7. **Use the Wordmark as delivered:** Galaxy on light or white on dark, never smaller
   than 116px, with "Q"-width clear space ([visual/logo.md](visual/logo.md)).
8. **Product palettes and lockups (Incentives, Planning, Catalyst, Agents) need
   approval** ([visual/product-palettes.md](visual/product-palettes.md)).
9. **Photography is a hero moment.** It should look natural, softly focused, and
   naturally lit. Don't overuse it ([visual/imagery.md](visual/imagery.md)).
10. **Never sample hex values from screenshots** or exported mockups, and never
    recreate or recolor a logo.

## Changes from the 2026-10-05 draft

- **Typography corrected.** The body font is **Fakt**, not Manrope. Manrope is legacy
  and appears only in product lockups. Free alternates are **Public Sans** and
  **Newsreader** (manual pp. 95–99).
- **Earlier open questions answered by the manual:**
  - Cirrus tints are tints of Cirrus 1 (p. 49).
  - `#9867FF`, `#14404F`, `#F98D55`, `#EFB6A6`, and `#2D7B81` are legacy or bridge
    colors in the full spectrum (p. 49).
  - Taupe 2 is `#DBD7D3` (p. 50).
- **The 14px CTA radius** came from the live site and is still open. The manual's
  system is 4/8/16/24px (see [visual/color.md](visual/color.md#open-questions-for-brand)).
