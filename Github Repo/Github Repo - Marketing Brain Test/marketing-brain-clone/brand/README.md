# Brand

This folder holds the parts of the CIQ Brand Manual & Style Guide 2.0 (September 2026)
that an assistant or teammate needs in order to write and design on brand. It's a
summary. The manual in the **Notion Brand Portal** (Notion → General → Brand) is still
the master copy. If the two disagree, the manual wins. Flag the gap so this folder can be fixed.

## Rules that apply everywhere

1. **Don't invent brand values.** That covers hex codes, fonts, taglines, and logo
   variants. If it isn't in these files or the manual, ask the brand team
   ([resources.md](resources.md#contacts)).
2. **Get logos and lockups from the brand team or the Notion Brand Portal.** Never
   recreate them, and never take them from a screenshot.
3. **Product pillar palettes and lockups aren't self-service.** Use them only in
   approved templates, or get approval first.
4. **The brand showcase (manual pp. 146–201) is inspiration, not instruction.**
   Follow the rules in sections 01–03 of the manual.
5. **These files are `status: draft`.** Tell the reader when you rely on them, until
   Brand signs off.
