## Six reasons (compete slides, Aug 2026)

1. Handle any comp plan, any complexity
2. Apply mid-year changes without rebuilding plans: calculations apply from the exact effective date
3. Reporting beyond the rep statement
4. Connect every data source (SmartGrid connectors)
5. A full SPM suite, not just commissions: sales planning and predictive modeling
6. Built for growth: scales from 10 to 10,000+ reps

## Where they're strong

Fast implementation (under 7 days, per the 2023 card).

## Where we win (2023 card, stale)

Plan flexibility, multi-currency handling (QuotaPath changes FX settings in the
background), and reps with different variables and rates.

## Their landmine

"If you have problems in Excel and put it in software that's also like Excel, those
problems won't go away." See [../objections.md](../objections.md).
