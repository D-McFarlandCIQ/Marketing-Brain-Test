## How we frame every competitor

From V6 messaging: each alternative forces a tradeoff. **Spreadsheets** are flexible
until you grow. **No-code tools** are fast until plans outgrow them. **Legacy suites**
scale, but they run on consultants and overnight batch jobs. CaptivateIQ has a live
calculation layer (SmartGrid) underneath. Every competitor sets the same landmine,
"CIQ is a glorified Excel", so see [../objections.md](../objections.md).
