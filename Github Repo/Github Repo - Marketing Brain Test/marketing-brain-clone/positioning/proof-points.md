# Proof points

The one list an assistant should quote stats, claims, and customer proof from.

> behind it. Until a row says `approved`, an assistant may use it in **internal**
> drafts only and must flag it. Never invent a stat, customer, or quote.

Status key: `approved` = cleared for external use · `in use` = appears in a shipped
asset but has no recorded approval or source · `unsourced` = no source found ·
`placeholder` = the source itself marks it TBD · `restricted` = usage limits apply.
