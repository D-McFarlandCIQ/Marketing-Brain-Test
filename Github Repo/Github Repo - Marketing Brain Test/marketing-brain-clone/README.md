# marketing-brain

Shared marketing context for CaptivateIQ teammates and their AI assistants.

> **Status: draft.** Nothing here is approved yet. The proposed layout is in
> [PROPOSAL.md](PROPOSAL.md). Comment there before we build anything out.

## What this will be

A repo you clone and open with your AI assistant (Claude Code, Claude Desktop,
or similar) so everyone works from the same source of truth:

- **Knowledge:** product, positioning, personas, competitors, brand voice, and
  marketing-ops definitions.
- **Skills:** step-by-step procedures the assistant follows, such as building an
  on-brand email, standardizing UTMs, uploading a campaign list, or creating a
  Salesforce report.
