# SmartGrid

**Current wording (Oct 2026):** "SmartGrid, our unified modeling workspace, is where
teams build and manage plans, quotas, territories, and payouts. All data is live and
connected, so a change in one area updates everything else the moment it happens."

V6 puts SmartGrid at the center of the story: the **live calculation layer** that every
product and agent builds on, and the one thing competitors lack. Exec feedback says the
real-time engine is necessary for agents ("agents need to operate with humans in real
time, not wait 20 minutes to process something").

## What it does (from the first-call deck)

Data connectors → data management → plans → payee experience → reporting, on any data
in any format.
- Go live and change plans in a fraction of the time, with real-time data management.
- Adapt to market changes in seconds, with real-time modeling.
- Process complex commission calculations in minutes.
- Reps see their earnings anytime.
- Real-time reporting.

## Naming

- Write **SmartGrid**: one word, capital S and G. Not "SmartGRID" or "Smartgrid".
- Older sources split it into "SmartGrid ELT" (the data layer) and "SmartGrid modeling
  engine". V6 folds both into one name.
- **Open decision:** exec feedback warns SmartGrid is becoming a blanket word. Until PMM
  decides, describe it as the "unified modeling workspace" and don't attach it to every feature.
