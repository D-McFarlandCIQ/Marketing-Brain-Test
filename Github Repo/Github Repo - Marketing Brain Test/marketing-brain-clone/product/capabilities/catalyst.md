# Catalyst

"Catalyst is the modeling workspace inside CaptivateIQ for forecasting, payout checks,
and scenario work." No exports and no new system to learn: one place to model payout
spend, quota performance, and account patterns on live CaptivateIQ data. Deck tagline:
"Model anything. Predict everything."

## Availability (internal release tracker)

- Catalyst (formerly "Workspaces"): **GA 2025-11-21**.
- Since then: payout anomaly detection model (GA Mar 2026), shared data resources (GA
  Mar 2026), enhancements (May 2026), and the **Catalyst Forecasting agent (GA Jun 10, 2026)**.
- Public page: [captivateiq.com/catalyst](https://www.captivateiq.com/catalyst). Public
  customer story: [Bandwidth](https://www.captivateiq.com/customers/bandwidth).

## Use cases

| Use case | What it does |
| --- | --- |
| Payout anomaly detection | Flags payout issues before payroll runs |
| Commission expense forecasting | Projects commission spend against budget |
| Attainment forecasting | Projects where attainment will land |
| Account scoring | Ranks accounts on past performance, for tiering and fair books |
| Pre-built visualizations | Dashboards on model output |

## How it works

1. Bring in data from CaptivateIQ, data workbooks, or CSV.
2. Build a model with formulas, or train an ML model in a few steps.
3. Apply the model and review the output. Version control, drill-down to transactions,
   and side-by-side scenarios are included.

## Talk track

Open with "which modeling jobs it can remove from your monthly cycles". Then position →
use cases → workflow → early customers → close on a deeper session with their own data.
