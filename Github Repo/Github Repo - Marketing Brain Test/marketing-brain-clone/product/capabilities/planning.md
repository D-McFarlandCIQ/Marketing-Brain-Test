# Planning (sales planning)

"Connect the dots between headcount, coverage, and quota." Territory, quota, and
capacity plans run on the same SmartGrid data as comp, so a re-plan flows straight into
incentives.

## Capabilities

| Area | What it does | Features |
| --- | --- | --- |
| **Sales capacity planning** | Model headcount needs that align to revenue goals | Quota-on-the-street modeling · to-be-hired (TBH) logic |
| **Quota setting** | Set and reconcile fair, achievable targets | Automated quota setting · top-down / bottom-up reconciliation |
| **Territory and account carving** | Design and assign equitable territories | GTM structure modeling · goal-based optimization · account dealer · collaboration |

Also: real-time scenarios with side-by-side comparison, version history and rollback,
approval flows, and Salesforce sync. The **Rev Planning agent** (GA Oct 2026) flags
unassigned accounts, quota gaps, and coverage problems, then models the fix. See
[agents.md](agents.md).

## Why it's different

- **Connected to comp.** Territory and quota outputs flow into commission models with
  no manual uploads or exports. Mid-year re-plans sync downstream.
- **Planning isn't annual anymore.** Poor plans ripple into quota disputes, missed
  coverage, and comp adjustments.

## Proof

Planning customer story from the Spreadsheets battlecard (customer **not named**, so
